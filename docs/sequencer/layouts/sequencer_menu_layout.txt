SEQUENCER MENU LAYOUT

Title examples:

- Sequencer
- Seq-BLUE MONDAY
- Seq-*BLUE MONDAY

Menu order:

  Keyboard
  Playback Settings
  Synth Options
  File Management
  New
  Save
  Save New
  Load
  Revert
  Color Options
  Tap Preview
  Update Firmware

Playback Settings submenu:

  Steps
  Direction
  Tempo
  Play Type
  MIDI Sync

MIDI Sync submenu:

  Clock Source
  Send Clock
  Send Transport

Color Options submenu:

  Color Mode
  Brightness
  Animation
  Rest Bright
  Dim Bright

Notes:

- The title includes the loaded file name when one is active.
- A leading * in the file part of the title means unsaved changes.
- Keyboard exits Sequencer mode and returns to normal board behavior.
- Color Options uses the same shared board settings as Keyboard mode.

SEQUENCER STEP TOOLS PICKER

This screen appears when the last button on the third row is pressed while a
step is selected.

Purpose:

- give quick key-based access to step editing tools without adding more items
  to the main Sequencer menu

Current OLED layout:

  Tools #13
  L 150% V 96 P 75%
  C3 E3 G3
  Len Vel Oct+ Oct-
  Prob Tie
  Cancel/Finished

Current active tool keys:

- first row key 1: Len
- first row key 2: Vel
- first row key 3: Oct+
- first row key 4: Oct-
- second row key 1: Prob
- second row key 2: Tie
- lower CANCEL key: exits the picker

Current behavior:

- Len opens the exact length screen for the selected step
- Vel opens the exact velocity screen for the selected step
- Prob opens the exact probability screen for the selected step
- Oct+ transposes the selected step up 1 octave and stays in the picker
- Oct- transposes the selected step down 1 octave and stays in the picker
- Tie currently shows a placeholder status message

LED behavior while the picker is open:

- tool keys are blue
- CANCEL is blue
- all other keys are off

Display behavior:

- this overlay keeps the display awake while it is open

HEXBOARD SEQUENCER MENU AND SETTINGS REQUIREMENTS

ID: SEQ-MENU-001
Title: Main Sequencer Menu
Status: Active
Area: Menus
Priority: High

Requirement:
The main Sequencer menu shall include the current top-level Sequencer actions
and settings.

Details:
- Keyboard
- Playback Settings
- Synth Options
- File Management
- Save
- Save New
- Load
- Revert
- Tap Preview
- Update Firmware


ID: SEQ-MENU-002
Title: File Management Submenu
Status: Active
Area: Menus
Priority: High

Requirement:
The File Management submenu shall include the current file-management actions.

Details:
- Rename File
- Rename Folder
- Create Folder
- Delete File
- Delete Folder
- USB Backup


ID: SEQ-MENU-003
Title: Shared Synth Options Access
Status: Active
Area: Menus
Priority: Medium

Requirement:
Sequencer mode shall provide access to Synth Options from the Sequencer menu.


ID: SEQ-MENU-004
Title: Firmware Update Access
Status: Active
Area: Menus
Priority: Medium

Requirement:
Sequencer mode shall provide access to firmware update reboot from the
Sequencer menu.


ID: SEQ-MENU-005
Title: Playback Settings Submenu
Status: Active
Area: Menus
Priority: High

Requirement:
The Sequencer menu shall provide a Playback Settings submenu for playback
configuration items.

Details:
- Steps
- Direction
- Tempo
- Play Type
- MIDI Sync


ID: SEQ-MENU-006
Title: Steps Setting
Status: Active
Area: Menus
Priority: High

Requirement:
The Steps menu item shall set the active playback step count.


ID: SEQ-MENU-007
Title: Direction Setting
Status: Active
Area: Menus
Priority: High

Requirement:
The Direction menu item shall set the current playback direction mode.


ID: SEQ-MENU-008
Title: Tempo Setting
Status: Active
Area: Menus
Priority: High

Requirement:
The Tempo menu item shall set the current BPM used by the sequencer step clock.


ID: SEQ-MENU-009
Title: Tap Preview Setting
Status: Active
Area: Menus
Priority: High

Requirement:
The Tap Preview menu item shall control whether selecting a step also previews
its stored notes.


ID: SEQ-MENU-010
Title: Play Type Setting
Status: Active
Area: Menus
Priority: High

Requirement:
The Play Type menu item shall switch between MIDI playback and onboard synth
playback.


ID: SEQ-MENU-012
Title: MIDI Sync Submenu
Status: Active
Area: Menus
Priority: High

Requirement:
The Playback Settings submenu shall provide a MIDI Sync submenu for clock and
transport sync settings.


ID: SEQ-MENU-013
Title: Clock Source Setting
Status: Active
Area: Menus
Priority: High

Requirement:
The MIDI Sync submenu shall provide a Clock Source setting with Internal and
External MIDI choices.


ID: SEQ-MENU-014
Title: Send Clock Setting
Status: Active
Area: Menus
Priority: Medium

Requirement:
The MIDI Sync submenu shall provide a Send Clock setting with Off and On
choices.


ID: SEQ-MENU-015
Title: Send Transport Setting
Status: Active
Area: Menus
Priority: Medium

Requirement:
The MIDI Sync submenu shall provide a Send Transport setting with Off and On
choices.


ID: SEQ-MENU-011
Title: Shared Menu Navigation Buttons
Status: Active
Area: Menus
Priority: Medium

Requirement:
When a menu page is active and the bottom command button below the encoder is
held, the top two command buttons below the encoder shall act like one encoder
step up and one encoder step down until that bottom button is released.

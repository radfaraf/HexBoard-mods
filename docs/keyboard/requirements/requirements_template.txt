EXAMPLE

ID: KB-PLAY-010
Title: Velocity Wheel Control
Status: Active
Area: Playing And Expression
Priority: High

Requirement:
Keyboard mode shall provide a dedicated command-button velocity wheel that
controls played note velocity.

Details:
- The top 3 command buttons make up the velocity wheel.
- The current velocity value shall be used for note-on velocity.
- The same current velocity value shall also be used for channel pressure where
  the firmware sends that message.

Notes:
- This requirement describes current wheel behavior inferred from the firmware.

- KB-PLAY-011

HEXBOARD KEYBOARD LAYOUT REFERENCES

These text files are reference sketches of important Keyboard-mode menus.

They are documentation only.

- They are not used by the firmware.
- They are meant to help remember current layout and menu behavior.
- Update them when a keyboard screen or menu structure changes in a meaningful
  way.

Confidence note

These files are currently based on the firmware menu behavior and are part of
the first structured Keyboard documentation pass.
